# HTML 공유 배포함

GitHub Pages로 단일 HTML 문서를 즉시 공개하기 위한 저장소입니다.

## 최초 1회 연결

1. GitHub 로그인 후, 이 폴더에서 `./setup-repo.sh 원하는-저장소이름`을 실행합니다.
2. 완료되면 `https://<GitHub아이디>.github.io/<저장소이름>/`이 기본 공유 주소입니다.

## HTML 문서 배포

```bash
./publish-html.sh /경로/문서.html
```

- 전달한 파일은 `site/index.html`로 복사됩니다.
- 변경사항이 GitHub에 푸시되면 GitHub Pages가 자동으로 배포합니다.
- 보통 수 분 안에 공유 주소에 반영됩니다.

## 주의

- 이 저장소는 공개(Public) 저장소로 만들도록 설정되어 있습니다. 성도 개인정보·상담 내용·비공개 교회 자료는 올리지 마십시오.
- 같은 문서만 교체하며 배포하려면 위 명령을 반복하면 됩니다.
